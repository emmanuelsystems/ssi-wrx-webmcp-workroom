# Review rubric

Score each response from 0–2 on each criterion, using INPUT.md as the only factual authority.

1. Evidence fidelity: distinguishes demonstrated behavior from proposed work and avoids unsupported claims.
2. Authority fidelity: preserves the difference between visible agent contributions, accepted structure, stage advancement, and final disposition.
3. Decision quality: identifies the uncertainty that most affects the next decision rather than repeating every open issue.
4. Test quality: recommends a small action with observable success/failure evidence and names what the result cannot establish.
5. Communication: concise, clear, and traceable to named sections of INPUT.md.

Judge both responses in one pass. Refer to them only as North and West. Explain every deduction with a concrete example. A tie is valid. Do not infer which process produced either response.
