STEP 3 · THE NEXT TEST IMPLEMENTATION

Test the handoff, not the whole architecture

Test hypothesis

A human can state or type an intent, review a structured intent card, explicitly confirm the allowed scope, and receive a bounded analysis package—without an agent advancing a stage or recording a decision.

Smallest build

Add a plane-aware Intent summary to the existing episode intake: objective, constraints, requested agent role, evidence request, and a human “confirm for analysis” action. It feeds the existing read-only intake/orchestration path.

What stays off

Voice capture, external tools, browser actions, file edits, stage advancement, final disposition, and any Agents API sandbox/tool capability.

Success signal

For three existing test episodes, a person can trace: original request → confirmed governance envelope → agent output → cited evidence → human next action. No authority boundary is crossed.
